# Thiranex – Predictive Modeling Using Machine Learning

This project was completed as part of my **Data Science Internship at Thiranex**, as a continuation of the data cleaning and visualization work.

## Project Overview

The project focuses on building machine learning models to predict **Purchase Amount** using customer shopping data.

## Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Excel

## Work Done

* Prepared the cleaned dataset for machine learning
* Performed feature engineering
* Encoded categorical features using One-Hot Encoding
* Created an Age Group feature
* Created a Category + Season feature
* Split the dataset into **70% training, 15% validation, and 15% testing**
* Built and compared:

  * Linear Regression
  * Decision Tree Regression
  * Random Forest Regression
  * Gradient Boosting Regression
* Tuned Random Forest parameters
* Evaluated models using **MAE, RMSE, and R²**
* Created Actual vs Predicted and model comparison visualizations

## Final Result

The **Random Forest Regression** model was selected based on the validation results.

* **Test MAE:** 25.98
* **Test RMSE:** 29.89
* **Test R²:** 0.0119

The results showed that the available customer features had a relatively weak relationship with Purchase Amount, providing practical experience in **regression modeling, feature preprocessing, model comparison, hyperparameter tuning, and model evaluation**.

This project extended my experience from data cleaning and visualization into **supervised machine learning and predictive analytics**, including model training, validation, testing, and performance evaluation.
