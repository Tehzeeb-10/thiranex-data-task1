# Thiranex – Data Cleaning & Visualization Project

This project was completed as part of my **Data Science Internship at Thiranex**.

## Project Overview

The project focuses on cleaning and analyzing a raw customer dataset and visualizing important insights using Python.

## Tools Used

* Python
* Pandas
* Matplotlib
* Excel

## Work Done

* Handled missing values
* Removed duplicate records
* Identified and analyzed outliers using the IQR method
* Performed basic statistical analysis
* Created visualizations for customer demographics, categories, subscriptions, seasons, and countries
* Generated a cleaned dataset
* Extracted key insights from the data

## Outcome

This project provided hands-on experience in **data preprocessing, data analysis, visualization, and data storytelling**.
